https://otofuda.github.io/

Introducing the OSS projects of the Otofuda Project

- Astro v5
- Node.js v22

## 📦 Projects

The Otofuda Project provides the following open source projects:

### [Chart Editor V2](https://otofuda.github.io/chart-editor/)
A tool for creating and editing Otofuda charts

### [Otofuda Portal](https://otofuda.com)
Official portal site of the Otofuda Project

### [StoryBuilder](https://otofuda.github.io/story-builder/)
Story building tool

### [Chart Types](https://github.com/otofuda/chart-types)
Type definition library for chart data

All projects are available on [GitHub](https://github.com/otofuda).

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
